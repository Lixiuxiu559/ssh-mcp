## 实现

- 八套方案为 A 薄荷奶绿、B 蜜桃奶杏、C 奶油薰衣草、D 海盐奶蓝、E 草莓奶霜、F 香蕉奶油、G 开心果奶、H 杏仁拿铁；本服务默认 **D 海盐奶蓝**。
- 每套仅 paper/pastel/ink 三个实体色；浅色与深色复用同组三色，不添加独立红绿状态色、透明度混色或阴影。状态保留文字/图标，危险操作保留确认并使用虚线边界。
- 登录页提供配色下拉框，账号偏好提供八套选择。独立键 `ssh-mcp-palette` 保存当前浏览器配色，兼容 `linkage-theme` 的 light/dark/auto。
- 配色与主题在首屏绘制前应用。无效 ID 与不可用存储回退服务默认，系统变化实时更新 auto。服务内独立持有全部 CSS/TypeScript，不在运行时依赖工作空间模板。

## 实际验证

- `npm --prefix webui run build`：TypeScript + Vite 构建通过。
- 浏览器实际逐一切换八套，刷新仍保留选择；登录页八套及刷新保存也通过。
- DB/SSH 使用不同默认配色及存储键。DB 的 auto 通过模拟系统 light/dark 验证实时跟随，随后恢复原 light 偏好。
- SSH 隔离演示环境验证无效配色 ID 与 localStorage 抛出 SecurityError 时仍可加载，回退 blue 和 auto。
- DB 薄荷奶绿、SSH 海盐奶蓝的浅/深页面，逐个可见元素提取实际文字、背景、边界、SVG 颜色，均只有对应三个原色。
- 八套 ink 对 paper / pastel 最低对比度分别为 7.18 / 5.96 / 6.43 / 5.92 / 5.95 / 6.11 / 6.29 / 6.04，均高于普通正文 4.5:1。
- 390px 视口：两个账号配色面板及 SSH 登录页无全页横向溢出；Esc 关闭弹窗可用。模板对照板自动单列，完整设计预览可切换配色。
- SSH 演示登录、总览、服务器列表及详情三标签通过。DB 演示登录、总览、实例列表通过；未执行目标连接或数据库/SSH 操作。
- `docs/images/workspace.png` 更新为隔离演示环境的实际截图，不使用真实凭据或业务资源。
- `uv build --offline`：wheel/sdist 构建通过。比对 wheel 内静态资源与本地构建逐字节一致，且不含 runtime、node_modules 或旧字体文件。
- 根、DB、SSH 的 `git diff --check` 均通过。
